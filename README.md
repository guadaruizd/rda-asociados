# RDA & Asociados

Sitio web del estudio jurídico **RDA & Asociados** (Asunción, Paraguay): defensa penal y asesoría jurídica.

Stack: React + TypeScript + Vite. Preparado para desplegar después en Vercel.

## Desarrollo

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Datos editables

Correo, WhatsApp, dirección y textos de servicios están centralizados en:

`src/config/site.ts`

Sustituya el monograma del logo por su archivo en `public/logo.svg` (o una imagen) dentro de `src/components/Logo.tsx`.
